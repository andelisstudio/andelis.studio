# Andelis Studio

Independent game studio in Coral Gables, Florida. Small puzzle games for iPhone, engineered with care. The first game is [Stelline](https://stelline.page/), on the [App Store](https://apps.apple.com/app/id6808032290).

This repository holds the studio's website, served from GitHub Pages at [andelis.studio](https://andelis.studio/): one page, no build step, no scripts, no cookies, no analytics.

- Contact: hello@andelis.studio. Press: press@andelis.studio, and the [Stelline press kit](https://stelline.page/press/).
- Support for Stelline: [stelline.page/support](https://stelline.page/support/). GitHub issues on this repository are not monitored for support.
